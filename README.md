- 🧠 Problem-solving ability

# 🧠 Problem-Solving Approach

For each problem, I try to follow a consistent process:

Understand the Problem
        ↓
Identify Constraints
        ↓
Build a Brute Force Approach
        ↓
Analyze Time & Space Complexity
        ↓
Identify Optimization / Pattern
        ↓
Implement
        ↓
Test Edge Cases
        ↓
Refactor & Review

This helps turn problem solving into a repeatable engineering process rather than memorizing solutions.


# ⚙️ Complexity Analysis

I focus on understanding the efficiency of each solution.

### Example


Problem: Two Sum

Brute Force
Time:  O(n²)
Space: O(1)

Optimized
Time:  O(n)
Space: O(n)


The repository is intended to document not only **what works**, but also **why it works and how efficiently it works**.
